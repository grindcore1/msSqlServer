# T-SQL и его отличия от стандартного SQL

**T-SQL (Transact-SQL)** — это диалект SQL от Microsoft (изначально совместно с Sybase), который используют в Microsoft SQL Server, Azure SQL и Azure Synapse. Он включает стандартный SQL (ANSI/ISO) и добавляет к нему процедурные возможности и собственные расширения.

Если коротко, обычный SQL — **декларативный**: вы описываете, _какие_ данные нужны. T-SQL добавляет **процедурную** часть: в нём можно писать настоящие программы с переменными, условиями и циклами.

## Главные отличия

### 1. Переменные

```sql
DECLARE @total INT;
SET @total = (SELECT COUNT(*) FROM Orders);
```

### 2. Управление потоком выполнения

`IF`, `WHILE`, `BEGIN…END`, `RETURN`, `GOTO`:

```sql
IF @total > 100
    PRINT 'Много заказов';
ELSE
    PRINT 'Мало заказов';

WHILE @i < 10
BEGIN
    SET @i += 1;
END
```

### 3. Обработка ошибок и транзакции

```sql
BEGIN TRY
    BEGIN TRANSACTION;
    UPDATE Accounts SET Balance -= 100 WHERE Id = 1;
    UPDATE Accounts SET Balance += 100 WHERE Id = 2;
    COMMIT;
END TRY
BEGIN CATCH
    ROLLBACK;
    SELECT ERROR_MESSAGE();
END CATCH
```

### 4. Хранимые процедуры, функции и триггеры

В них можно писать логику на T-SQL: `CREATE PROCEDURE`, `CREATE FUNCTION`, `CREATE TRIGGER`.

### 5. Синтаксис, специфичный для SQL Server

|Задача|Стандарт / другие СУБД|T-SQL|
|---|---|---|
|Ограничить число строк|`LIMIT 10` / `FETCH FIRST 10 ROWS`|`SELECT TOP 10 ...`|
|Текущая дата|`CURRENT_TIMESTAMP`|`GETDATE()` (стандартный тоже работает)|
|Склейка строк|`\|`|`+` или `CONCAT()`|
|Автоинкремент|`GENERATED AS IDENTITY` / `SERIAL`|`IDENTITY(1,1)`|
|Проверка на NULL|`COALESCE`|`ISNULL()` (плюс `COALESCE`)|

### 6. Прочие расширения

- Временные таблицы (`#temp`, `##global`)
- Табличные переменные (`@table`)
- `OUTPUT` в `INSERT` / `UPDATE` / `DELETE`
- `MERGE`
- `CROSS APPLY` / `OUTER APPLY`
- `PIVOT` / `UNPIVOT`
- `TRY_CAST` / `TRY_CONVERT`

## Для сравнения

У других СУБД есть свои процедурные расширения: **PL/SQL** в Oracle и **PL/pgSQL** в PostgreSQL. Поэтому код на T-SQL обычно не переносится на другие СУБД без правок. Переносимы только простые запросы, написанные на стандартном SQL: `SELECT`, `JOIN`, `GROUP BY` и т. п.
