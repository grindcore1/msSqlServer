# ПР 17.09 - Книжный интернет-магазин: схема и данные

- **Предметная область:** книжный интернет-магазин
- **СУБД:** Microsoft SQL Server 2025 (SSMS 22)
- **База данных:** BookStoreDB
- **Срок:** 17.09

## 1. Схема базы данных (3NF)

Таблицы: Authors, Books, Categories, BookCategories (связь книга - категории, M:N), Customers, Orders, OrderItems (позиции заказа, чтобы в одном заказе было несколько книг). Списки через запятую не хранятся, цена позиции фиксируется в OrderItems.UnitPrice на момент заказа. Первичный ключ Orders некластерный, чтобы кластерный индекс можно было построить по OrderDate (задание следующей работы).

**Код**

```sql
USE master;
GO
IF DB_ID(N'BookStoreDB') IS NOT NULL
BEGIN
    ALTER DATABASE BookStoreDB SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
    DROP DATABASE BookStoreDB;
END
GO
CREATE DATABASE BookStoreDB;
GO
USE BookStoreDB;
GO
CREATE TABLE dbo.Authors (
    AuthorId  INT IDENTITY(1,1) NOT NULL CONSTRAINT PK_Authors PRIMARY KEY,
    FullName  NVARCHAR(100) NOT NULL,
    Country   NVARCHAR(50)  NULL,
    BirthYear INT NULL CONSTRAINT CHK_Authors_BirthYear CHECK (BirthYear BETWEEN 1500 AND 2020)
);

CREATE TABLE dbo.Categories (
    CategoryId INT IDENTITY(1,1) NOT NULL CONSTRAINT PK_Categories PRIMARY KEY,
    Name       NVARCHAR(50) NOT NULL CONSTRAINT UQ_Categories_Name UNIQUE
);

CREATE TABLE dbo.Books (
    BookId      INT IDENTITY(1,1) NOT NULL CONSTRAINT PK_Books PRIMARY KEY,
    Title       NVARCHAR(200) NOT NULL,
    AuthorId    INT NOT NULL,
    Price       DECIMAL(10,2) NOT NULL CONSTRAINT CHK_Books_Price CHECK (Price > 0),
    StockQty    INT NOT NULL CONSTRAINT DF_Books_StockQty DEFAULT 0
                CONSTRAINT CHK_Books_StockQty CHECK (StockQty >= 0),
    PublishYear INT NULL CONSTRAINT CHK_Books_PublishYear CHECK (PublishYear BETWEEN 1450 AND 2100),
    CONSTRAINT FK_Books_Authors FOREIGN KEY (AuthorId) REFERENCES dbo.Authors(AuthorId)
);

CREATE TABLE dbo.BookCategories (
    BookId     INT NOT NULL,
    CategoryId INT NOT NULL,
    CONSTRAINT PK_BookCategories PRIMARY KEY (BookId, CategoryId),
    CONSTRAINT FK_BookCategories_Books FOREIGN KEY (BookId) REFERENCES dbo.Books(BookId),
    CONSTRAINT FK_BookCategories_Categories FOREIGN KEY (CategoryId) REFERENCES dbo.Categories(CategoryId)
);

CREATE TABLE dbo.Customers (
    CustomerId INT IDENTITY(1,1) NOT NULL CONSTRAINT PK_Customers PRIMARY KEY,
    FullName   NVARCHAR(100) NOT NULL,
    Email      NVARCHAR(100) NOT NULL CONSTRAINT UQ_Customers_Email UNIQUE,
    Phone      NVARCHAR(20)  NULL,
    City       NVARCHAR(50)  NOT NULL
);

CREATE TABLE dbo.Orders (
    OrderId    INT IDENTITY(1,1) NOT NULL CONSTRAINT PK_Orders PRIMARY KEY NONCLUSTERED,
    CustomerId INT NOT NULL,
    OrderDate  DATETIME2(0) NOT NULL CONSTRAINT DF_Orders_OrderDate DEFAULT SYSDATETIME(),
    Status     NVARCHAR(20) NOT NULL CONSTRAINT DF_Orders_Status DEFAULT N'Pending'
               CONSTRAINT CHK_Orders_Status CHECK (Status IN (N'Pending', N'Shipped', N'Delivered', N'Cancelled')),
    CONSTRAINT FK_Orders_Customers FOREIGN KEY (CustomerId) REFERENCES dbo.Customers(CustomerId)
);

CREATE TABLE dbo.OrderItems (
    OrderId   INT NOT NULL,
    BookId    INT NOT NULL,
    Quantity  INT NOT NULL CONSTRAINT CHK_OrderItems_Quantity CHECK (Quantity > 0),
    UnitPrice DECIMAL(10,2) NOT NULL CONSTRAINT CHK_OrderItems_UnitPrice CHECK (UnitPrice > 0),
    CONSTRAINT PK_OrderItems PRIMARY KEY (OrderId, BookId),
    CONSTRAINT FK_OrderItems_Orders FOREIGN KEY (OrderId) REFERENCES dbo.Orders(OrderId),
    CONSTRAINT FK_OrderItems_Books FOREIGN KEY (BookId) REFERENCES dbo.Books(BookId)
);
```

## 3. Проверка данных

**Тест**

```sql
SELECT N'Authors' AS TableName, COUNT(*) AS RowsCount FROM dbo.Authors
UNION ALL SELECT N'Categories', COUNT(*) FROM dbo.Categories
UNION ALL SELECT N'Books', COUNT(*) FROM dbo.Books
UNION ALL SELECT N'BookCategories', COUNT(*) FROM dbo.BookCategories
UNION ALL SELECT N'Customers', COUNT(*) FROM dbo.Customers
UNION ALL SELECT N'Orders', COUNT(*) FROM dbo.Orders
UNION ALL SELECT N'OrderItems', COUNT(*) FROM dbo.OrderItems;
```

**Результат:** Authors 6, Categories 5, Books 9, BookCategories 16, Customers 6, Orders 9, OrderItems 16.

Скриншот 2. Количество строк в таблицах

![[магазин17_02.png]]

**Тест**

```sql
SELECT b.BookId, b.Title, a.FullName AS Author, b.Price, b.StockQty,
       STRING_AGG(c.Name, N', ') WITHIN GROUP (ORDER BY c.Name) AS Categories
FROM dbo.Books b
JOIN dbo.Authors a ON a.AuthorId = b.AuthorId
JOIN dbo.BookCategories bc ON bc.BookId = b.BookId
JOIN dbo.Categories c ON c.CategoryId = bc.CategoryId
GROUP BY b.BookId, b.Title, a.FullName, b.Price, b.StockQty
ORDER BY b.BookId;
```

**Результат:** у книг по 1-3 категории, например «Преступление и наказание» - Детектив, Классика, Роман.

Скриншот 3. Книги с авторами и категориями

![[магазин17_03.png]]

**Тест**

```sql
SELECT o.OrderId, cu.FullName AS Customer, o.OrderDate, o.Status,
       COUNT(oi.BookId) AS Positions, SUM(oi.Quantity) AS BooksQty,
       SUM(oi.Quantity * oi.UnitPrice) AS OrderSum
FROM dbo.Orders o
JOIN dbo.Customers cu ON cu.CustomerId = o.CustomerId
JOIN dbo.OrderItems oi ON oi.OrderId = o.OrderId
GROUP BY o.OrderId, cu.FullName, o.OrderDate, o.Status
ORDER BY o.OrderId;
```

**Результат:** 9 заказов, в заказах 1, 2 и 7 по несколько книг (до 3 позиций), количество книг в позиции от 1 до 4.

Скриншот 4. Заказы с количеством позиций и суммой

```sql
SELECT N'Позиции с несуществующей книгой' AS CheckName, COUNT(*) AS BadRows
FROM dbo.OrderItems oi
```
