## Схема и тестовые данные

Схема и данные из задания. Даты со временем записаны в формате ISO (2025-09-17T09:00:00): при русском языке сервера строка «2025-09-17 09:00» для DATETIME читается как год-день-месяц и даёт ошибку 242.

## Таблица обоснований

| № | Выбранный объект | Почему этот, а не другой? | Почему альтернативы не подходят? |
|---|---|---|---|
| 1 | Триггер AFTER INSERT, UPDATE на Rentals (trg_Rentals_StatusLog) | Журнал должен заполняться при любом изменении статуса: из процедуры, прямым UPDATE, из приложения. Триггер срабатывает всегда и видит старое (deleted) и новое (inserted) значение | Процедуру можно обойти прямым UPDATE, и оператор забудет запись. Функция не может делать INSERT |
| 2 | Скалярная функция fn_EstimatedRangeKm | Это расчёт, который нужен внутри SELECT, WHERE, отчётов и других объектов (используется в StartRental) | Процедуру нельзя вызвать внутри SELECT. Триггер не возвращает значение, а хранить вычисляемое значение в таблице - дублирование |
| 3 | Хранимая процедура StartRental | Действие с параметрами, несколькими проверками, транзакцией и понятными ошибками, меняет две таблицы (Rentals и Cars) | Функция не может менять данные. Триггер срабатывает на уже сделанное изменение и не принимает параметры операции |
| 4 | Хранимая процедура CompleteRental | Многошаговая атомарная операция: Rentals, Cars, Drivers в одной транзакции, с проверками и THROW | Функция не может делать UPDATE. В триггере сложно передать параметры (пробег, заряд, авария) и управлять ошибками |
| 5 | Триггер AFTER UPDATE на Cars (trg_Cars_LowBatteryToCharging) | Перевод в Charging должен происходить автоматически при любом снижении заряда, не только из CompleteRental | Процедура сработает только если её вызвать. Функция не меняет данные |
| 6 | Скалярная функция fn_DriverReliability | Расчёт показателя для SELECT и отчётов по водителям | Процедура не встраивается в SELECT. Триггер и хранимый столбец дублируют данные и требуют синхронизации |
| 7 | Хранимая процедура FinishCharging | Оператор фиксирует окончание зарядки с параметрами, нужны проверки (ChargeTo >= ChargeFrom), атомарное обновление ChargingLogs и Cars | Функция не может менять данные. Триггер на ChargingLogs не проверит входные параметры до изменения и хуже сообщает об ошибке |
| 8 | Триггер AFTER INSERT, UPDATE на Rentals (trg_Rentals_BlockUnavailableCar) | Гарантия на уровне БД: проверка срабатывает при любом способе назначить авто, в том числе прямом UPDATE | Проверку в процедуре обходит прямой UPDATE или приложение. CHECK-ограничение не может обращаться к другой таблице без функции, а функция в CHECK не даёт понятного текста ошибки |

## Требование 1. Автоматический журнал статусов аренды

**Код**

```sql
CREATE OR ALTER TRIGGER dbo.trg_Rentals_StatusLog
ON dbo.Rentals
AFTER INSERT, UPDATE
AS
BEGIN
    SET NOCOUNT ON;
    INSERT dbo.RentalStatusLog (RentalId, OldStatus, NewStatus, ChangedAt, ChangedBy)
    SELECT i.RentalId, d.Status, i.Status, GETDATE(), SYSTEM_USER
    FROM inserted i
    LEFT JOIN deleted d ON d.RentalId = i.RentalId
    WHERE d.RentalId IS NULL OR d.Status <> i.Status;
END;
```

**Тест**

```sql
UPDATE dbo.Rentals SET Status = N'Disputed' WHERE RentalId = 1;
UPDATE dbo.Rentals SET ExtraCost = 100 WHERE RentalId = 2;
SELECT N'Т1 Журнал статусов' AS Test, LogId, RentalId, ISNULL(OldStatus, N'NULL') AS OldStatus, NewStatus, ChangedAt, ChangedBy
FROM dbo.RentalStatusLog
ORDER BY LogId;
```

**Результат:** Смена статуса аренды 1 на Disputed и изменение ExtraCost у аренды 2 без смены статуса. В журнале 4 записи: NULL -> Active (новая аренда 5), Active -> Completed (аренды 3 и 4), Completed -> Disputed (аренда 1), ChangedBy = DESKTOP-02P5L82\nazva. Изменение ExtraCost в журнал не попало.

## Требование 2. Расчёт примерного запаса хода

**Код**

```sql
CREATE OR ALTER FUNCTION dbo.fn_EstimatedRangeKm (@MaxRangeKm INT, @BatteryLevel INT)
RETURNS DECIMAL(8,2)
AS
BEGIN
    IF @MaxRangeKm IS NULL OR @BatteryLevel IS NULL OR @MaxRangeKm <= 0 OR @BatteryLevel NOT BETWEEN 0 AND 100
        RETURN NULL;
    RETURN CAST(@MaxRangeKm * (@BatteryLevel / 100.0) AS DECIMAL(8,2));
END;
```

**Тест**

```sql
SELECT N'Т2.1 Запас хода' AS Test, CarId, Model, MaxRangeKm, BatteryLevel,
       dbo.fn_EstimatedRangeKm(MaxRangeKm, BatteryLevel) AS EstimatedRangeKm, Status
FROM dbo.Cars
ORDER BY EstimatedRangeKm DESC;
```

## Требование 3. Оформление аренды авто

**Код**

```sql
CREATE OR ALTER PROCEDURE dbo.StartRental
    @CustomerId INT,
    @CarId      INT,
    @DriverId   INT,
    @BaseCost   DECIMAL(10,2),
    @RentalId   INT OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;
    DECLARE @Msg NVARCHAR(400), @Model NVARCHAR(50), @CarStatus NVARCHAR(20), @MaxRange INT, @Battery INT,
            @Mileage DECIMAL(10,2), @DriverName NVARCHAR(100), @Expiry DATE, @DriverActive BIT, @Range DECIMAL(8,2);
    BEGIN TRY
        BEGIN TRANSACTION;
            IF NOT EXISTS (SELECT 1 FROM dbo.Customers WHERE CustomerId = @CustomerId)
            BEGIN
                SET @Msg = CONCAT(N'Клиент с CustomerId = ', @CustomerId, N' не найден.');
                THROW 52301, @Msg, 1;
            END;

            SELECT @Model = Model, @CarStatus = Status, @MaxRange = MaxRangeKm, @Battery = BatteryLevel, @Mileage = CurrentMileage
            FROM dbo.Cars WITH (UPDLOCK, HOLDLOCK)
            WHERE CarId = @CarId;

            IF @Model IS NULL
            BEGIN
                SET @Msg = CONCAT(N'Автомобиль с CarId = ', @CarId, N' не найден.');
                THROW 52302, @Msg, 1;
            END;
            IF @CarStatus <> N'Available'
            BEGIN
                SET @Msg = CONCAT(N'Автомобиль ', @Model, N' (CarId = ', @CarId, N') недоступен: статус ', @CarStatus, N'.');
                THROW 52303, @Msg, 1;
            END;
            IF EXISTS (SELECT 1 FROM dbo.Rentals WHERE CarId = @CarId AND Status = N'Active')
            BEGIN
                SET @Msg = CONCAT(N'Автомобиль ', @Model, N' (CarId = ', @CarId, N') уже находится в активной аренде.');
                THROW 52304, @Msg, 1;
            END;

            SELECT @DriverName = FullName, @Expiry = LicenseExpiry, @DriverActive = IsActive
            FROM dbo.Drivers
            WHERE DriverId = @DriverId;

            IF @DriverName IS NULL OR @DriverActive = 0
            BEGIN
                SET @Msg = CONCAT(N'Водитель с DriverId = ', @DriverId, N' не найден или неактивен.');
                THROW 52305, @Msg, 1;
            END;
            IF @Expiry < CAST(GETDATE() AS DATE)
            BEGIN
                SET @Msg = CONCAT(N'У водителя ', @DriverName, N' истекла лицензия (', CONVERT(NVARCHAR(10), @Expiry, 104), N').');
                THROW 52306, @Msg, 1;
            END;

            SET @Range = dbo.fn_EstimatedRangeKm(@MaxRange, @Battery);
            IF @Range < @MaxRange * 0.3
            BEGIN
                SET @Msg = CONCAT(N'Недостаточно заряда: запас хода ', @Range, N' км при минимуме ', CAST(@MaxRange * 0.3 AS DECIMAL(8,2)), N' км (заряд ', @Battery, N' проц.).');
                THROW 52307, @Msg, 1;
            END;
            IF @BaseCost IS NULL OR @BaseCost <= 0
            BEGIN
                SET @Msg = N'Базовая стоимость аренды должна быть больше нуля.';
                THROW 52308, @Msg, 1;
            END;

            INSERT dbo.Rentals (CustomerId, CarId, DriverId, StartAt, StartOdometer, BaseCost, Status)
            VALUES (@CustomerId, @CarId, @DriverId, GETDATE(), @Mileage, @BaseCost, N'Active');
            SET @RentalId = SCOPE_IDENTITY();

            UPDATE dbo.Cars SET Status = N'Rented' WHERE CarId = @CarId;
        COMMIT TRANSACTION;
    END TRY
    BEGIN CATCH
        IF @@TRANCOUNT > 0 ROLLBACK TRANSACTION;
        THROW;
    END CATCH;
END;
```

## Требование 4. Фиксация завершения аренды и расчёт стоимости

**Код**

```sql
CREATE OR ALTER PROCEDURE dbo.CompleteRental
    @RentalId        INT,
    @EndOdometer     DECIMAL(10,2),
    @EndBatteryLevel INT,
    @ExtraCost       DECIMAL(10,2) = 0,
    @HadAccident     BIT = 0
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;
    DECLARE @Msg NVARCHAR(400), @Status NVARCHAR(20), @CarId INT, @DriverId INT,
            @StartOdo DECIMAL(10,2), @Distance DECIMAL(10,2);
    BEGIN TRY
        BEGIN TRANSACTION;
            SELECT @Status = Status, @CarId = CarId, @DriverId = DriverId, @StartOdo = StartOdometer
            FROM dbo.Rentals WITH (UPDLOCK, HOLDLOCK)
            WHERE RentalId = @RentalId;

            IF @Status IS NULL
            BEGIN
                SET @Msg = CONCAT(N'Аренда с RentalId = ', @RentalId, N' не найдена.');
                THROW 52401, @Msg, 1;
            END;
            IF @Status <> N'Active'
            BEGIN
                SET @Msg = CONCAT(N'Аренда ', @RentalId, N' имеет статус ', @Status, N'. Закрыть можно только активную аренду.');
                THROW 52402, @Msg, 1;
            END;
            IF @EndOdometer IS NULL OR @EndOdometer < @StartOdo
            BEGIN
                SET @Msg = CONCAT(N'Конечный пробег ', @EndOdometer, N' меньше начального ', @StartOdo, N'.');
                THROW 52403, @Msg, 1;
            END;
            IF @EndBatteryLevel IS NULL OR @EndBatteryLevel NOT BETWEEN 0 AND 100
            BEGIN
                SET @Msg = CONCAT(N'Некорректный уровень заряда: ', @EndBatteryLevel, N'.');
                THROW 52404, @Msg, 1;
            END;
            IF @ExtraCost < 0
            BEGIN
                SET @Msg = N'Доплата не может быть отрицательной.';
                THROW 52405, @Msg, 1;
            END;

            SET @Distance = @EndOdometer - @StartOdo;

            UPDATE dbo.Rentals
            SET EndAt = GETDATE(),
                EndOdometer = @EndOdometer,
                DistanceCovered = @Distance,
                ExtraCost = @ExtraCost,
                TotalCost = BaseCost + @ExtraCost,
                Status = N'Completed'
            WHERE RentalId = @RentalId;

            UPDATE dbo.Cars
            SET CurrentMileage = @EndOdometer,
                BatteryLevel = @EndBatteryLevel,
                Status = CASE WHEN @HadAccident = 1 THEN N'Accident' ELSE N'Available' END
            WHERE CarId = @CarId;

            UPDATE dbo.Drivers
            SET TotalRents = TotalRents + 1,
                TotalDistance = TotalDistance + @Distance,
                AccidentCount = AccidentCount + CASE WHEN @HadAccident = 1 THEN 1 ELSE 0 END
            WHERE DriverId = @DriverId;
        COMMIT TRANSACTION;
    END TRY
    BEGIN CATCH
        IF @@TRANCOUNT > 0 ROLLBACK TRANSACTION;
        THROW;
    END CATCH;
END;
```

## Требование 6. Рейтинг надёжности водителя

**Код**

```sql
CREATE OR ALTER FUNCTION dbo.fn_DriverReliability (@TotalRents INT, @AccidentCount INT)
RETURNS DECIMAL(5,2)
AS
BEGIN
    DECLARE @Result DECIMAL(5,2);
    IF @TotalRents IS NULL OR @TotalRents <= 0
        RETURN 0;
    SET @Result = (@TotalRents - ISNULL(@AccidentCount, 0)) * 100.0 / @TotalRents;
    RETURN CASE WHEN @Result < 0 THEN 0 WHEN @Result > 100 THEN 100 ELSE @Result END;
END;
```

## Требование 7. Фиксация зарядки и восстановление заряда

**Код**

```sql
CREATE OR ALTER PROCEDURE dbo.FinishCharging
    @LogId       INT,
    @ChargeTo    INT,
    @ChargingEnd DATETIME = NULL
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;
    DECLARE @Msg NVARCHAR(400), @CarId INT, @ChargeFrom INT, @End DATETIME, @Start DATETIME;
    BEGIN TRY
        BEGIN TRANSACTION;
            SELECT @CarId = CarId, @ChargeFrom = ChargeFrom, @End = ChargingEnd, @Start = ChargingStart
            FROM dbo.ChargingLogs WITH (UPDLOCK, HOLDLOCK)
            WHERE LogId = @LogId;

            IF @CarId IS NULL
            BEGIN
                SET @Msg = CONCAT(N'Запись о зарядке LogId = ', @LogId, N' не найдена.');
                THROW 52701, @Msg, 1;
            END;
            IF @End IS NOT NULL
            BEGIN
                SET @Msg = CONCAT(N'Зарядка LogId = ', @LogId, N' уже завершена ', CONVERT(NVARCHAR(16), @End, 120), N'.');
                THROW 52702, @Msg, 1;
            END;
            IF @ChargeTo IS NULL OR @ChargeTo NOT BETWEEN 0 AND 100
            BEGIN
                SET @Msg = CONCAT(N'Некорректный уровень заряда ChargeTo = ', @ChargeTo, N'.');
                THROW 52703, @Msg, 1;
            END;
            IF @ChargeTo < @ChargeFrom
            BEGIN
                SET @Msg = CONCAT(N'Уровень после зарядки (', @ChargeTo, N') меньше уровня до зарядки (', @ChargeFrom, N').');
                THROW 52704, @Msg, 1;
            END;

            SET @ChargingEnd = ISNULL(@ChargingEnd, GETDATE());
            IF @ChargingEnd < @Start
            BEGIN
                SET @Msg = N'Время окончания зарядки раньше времени начала.';
                THROW 52705, @Msg, 1;
            END;

            UPDATE dbo.ChargingLogs
            SET ChargingEnd = @ChargingEnd,
                ChargeTo = @ChargeTo,
                EnergyConsumedKwh = @ChargeTo - ISNULL(@ChargeFrom, 0)
            WHERE LogId = @LogId;

            UPDATE dbo.Cars
            SET BatteryLevel = @ChargeTo,
                Status = CASE WHEN Status = N'Charging' THEN N'Available' ELSE Status END
            WHERE CarId = @CarId;
        COMMIT TRANSACTION;
    END TRY
    BEGIN CATCH
        IF @@TRANCOUNT > 0 ROLLBACK TRANSACTION;
        THROW;
    END CATCH;
END;
```

## Требование 8. Защита от аренды неисправного авто

**Код**

```sql
CREATE OR ALTER TRIGGER dbo.trg_Rentals_BlockUnavailableCar
ON dbo.Rentals
AFTER INSERT, UPDATE
AS
BEGIN
    SET NOCOUNT ON;
    DECLARE @Msg NVARCHAR(400);
    IF NOT UPDATE(CarId) RETURN;

    IF EXISTS (SELECT 1
               FROM inserted i
               LEFT JOIN deleted d ON d.RentalId = i.RentalId
               JOIN dbo.Cars c ON c.CarId = i.CarId
               WHERE (d.RentalId IS NULL OR d.CarId <> i.CarId)
                 AND c.Status IN (N'Maintenance', N'Accident', N'Charging'))
    BEGIN
        SELECT TOP (1) @Msg = CONCAT(N'Автомобиль ', c.Model, N' (CarId = ', c.CarId, N') находится в статусе ', c.Status,
                                     N' и не может быть назначен на аренду ', i.RentalId, N'.')
        FROM inserted i
        LEFT JOIN deleted d ON d.RentalId = i.RentalId
        JOIN dbo.Cars c ON c.CarId = i.CarId
        WHERE (d.RentalId IS NULL OR d.CarId <> i.CarId)
          AND c.Status IN (N'Maintenance', N'Accident', N'Charging');
        ROLLBACK TRANSACTION;
        THROW 52801, @Msg, 1;
    END;
END;
```

**Тест**


**Результат:** Ошибка 52801 «Автомобиль Nissan Leaf (CarId = 5) находится в статусе Maintenance и не может быть назначен на аренду 4.».
